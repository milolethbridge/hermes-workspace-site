Privacy Policy

Hermes Workspace - last updated 27 October 2026

Hermes Workspace ("the app") is a private automation tool with a single user, the owner of the Google account that authorises it. This policy explains what Google user data the app accesses, how it is stored, and how it is used.

Google user data the app accesses

  • Gmail (gmail.modify): message metadata, bodies and attachments, and sending mail from the owner's mailbox.
  • Google Drive (drive): file names, metadata and file contents in the owner's Drive.
  • Google Calendar (calendar): calendars and events.
  • Google Sheets (spreadsheets): spreadsheet values.
  • Basic account identity (userinfo.email): the email address of the authorising account.

How data is stored

  • An OAuth refresh token is stored in a private, access-controlled secrets manager on hardware the owner controls.
  • Data retrieved from Google is held only transiently in memory or in local working files needed to complete the owner's request, and is not copied into any third-party service.
  • No Google user data is sold, rented, or transferred to advertisers, data brokers, or any other third party.

How data is used

  • Only to carry out tasks the owner explicitly asks the app to perform (for example: find an email, summarise a document, add a calendar event).
  • Some processing is performed by large language model providers to interpret requests. Only the minimum content needed for the specific task is sent, and it is not used to train third-party models where the provider offers a no-training option, which is selected wherever available.

Limited use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

  • Access can be revoked at any time at myaccount.google.com/permissions, which immediately ends the app's access.
  • Local working copies of retrieved data are deleted when the task finishes or within 30 days at most.
  • The owner may request deletion of any retained data by email; it is removed within 7 days.
